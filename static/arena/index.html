The ledger is empty. Every evaluation you run appears here, keyed so a retry costs nothing and a new hypothesis costs a trial.

Margin over chance is the best score found minus the best a run of matched nulls of the same effective size would reach. The allowance shown above the buttons is that correction, and it falls as the search widens, which is the discount doing its work. On this particular data it stays small, because an uninformative candidate reliably costs something here rather than helping by luck, so a wide search cannot manufacture a gain. That is itself the reading: this space is safe to explore. A noisier one would not be, and the same instrument would say so.

The seal is two folds of data no selection in this pool was ever allowed to touch. In a live system it is the future, arriving on its own schedule.

One · the capability

built · in daily use

An agentic analysis platform, already running

I built the agent layer of a live options and volatility research console that a practising trader uses daily. Fifty-four skills in four tiers, each with a formal contract rather than free-form text, discovered by a registry that turns every exported function into a runnable action. Higher tiers compose lower ones, so a single morning call fans out into a dozen grounded sub-answers.

Two design choices matter for everything that follows. Every skill declares a typed contract, which is what makes a fabricated field a load error rather than a plausible sentence. And 49 of the 54 write a forensic row on every call into locked, schema-checked, date-partitioned storage, already aggregated across the system. The meter exists and is hardened. Today it counts what the research spends on vendor APIs, not how many hypotheses were tried.

Two · what breaks the moment it acts

Analysis is replayable. Action is not.

Idempotency

A retried backtest costs nothing. A retried order is a second position and a retried payment is a second payment. The key has to come from the intent, never from the call.

Hallucination

A fabricated citation is embarrassing. A fabricated fill price moves money. Constrain every tool output by schema and reconcile every asserted fact before it can reach an order.

Sandbox and seal

Capability tokens bounding notional, instruments and time, so a violation is structurally impossible. And what the agent may observe of its own P&L is a design parameter.

Three · and how anyone could tell it improved

A system that appears to improve with use looks exactly like one that is overfitting harder

So the hard half of self-evolution is the measurement, not the evolution. What follows is that measurement, run end to end on real data.

3.3 · the calibration

real data · dev/prelim.py, dev/prelim_hard_null.py

An acceptance rule with a measured error rate, not an assumed one

A null candidate is the same construction evaluated on a randomly chosen other day from the same site. It keeps the column count, the marginal distribution, the per-hour distribution and the within-day shape, and destroys only the alignment to the target, so it carries no information by construction. Put 64 of them through the identical gate and count how many get in.

3.4 · nominal versus effective

real data · dev/prelim.py

Twenty-four tries is not twenty-four tries, and junk makes it worse

Correcting a result by the raw number of attempts over-penalises a researcher who examined one idea from twenty angles. The quantity the theory wants is the number of independent attempts, read off the eigenvalues of the correlation matrix of what each candidate actually improved.

Four · the system this becomes

Four parts, and why the agent must not own the denominator

Meter

Every evaluation is an API call the platform records, keyed so a crash-retry costs nothing and a nudged parameter costs a trial. The party being graded never supplies its own denominator.

Calibrator

Manufactures matched nulls on demand and measures what the acceptance rule's error rate actually is.

Deflator

Estimates Neff from the ledger online and returns a discounted score. Never a raw one.

Attestation

Result, effective trial count, seal schedule and a replayable record, signed and travelling with the agent.

The self-improvement harness rides on top. The agent may rewrite its own search policy, but its fitness signal is the deflated score. That single substitution is what separates improving from self-deceiving.

Two details decide whether the meter is real. Trial identity has to be an idempotency key that absorbs a crash-retry without incrementing the count, yet refuses to let a renamed variable buy a fresh one. And replay only means anything if the data is pinned, because prices get adjusted and fundamentals get restated, so every ledger row names the content-addressed snapshot it saw.
